把音乐导入 iPod nano

NanoBridge 已完成 AAC 音频准备。当前版本通过独立导入工具传输，不需要 Apple“音乐”App。

  1. 用数据线连接 iPod，并确保 Windows 能看到它的磁盘。
  2. 在 Chrome 或 Edge 打开 TunesReloaded，按页面提示识别设备并选择 iPod 根目录。
  3. 添加 NanoBridge 输出文件夹中的 M4A 文件，点击 Sync，等待工具报告完成后安全弹出。

应用目前尚未内置设备数据库直写。这里只会将转换状态标记为“已转换”，不会将音频准备当成已传输。
